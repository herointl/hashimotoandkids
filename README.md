# こども発達らぼ ＆kids橋本｜ホームページ（デザイン版）

構成案 `andkids_hashimoto_site_structure.docx` に沿って制作した、複数ページ構成の静的HTMLサイトです。
のちの WordPress 化を前提に、ヘッダー／フッター／CTA を共通パーツとして切り出しやすい構造にしています。

---

## 1. ファイル構成

```
&kids橋本2/
├─ index.html          … ①ホーム
├─ about.html          … ②＆kids橋本について
├─ program.html        … ③支援内容・プログラム
├─ guide.html          … ④ご利用案内
├─ access.html         … ⑤アクセス・施設概要
├─ news.html           … ⑥お知らせ
├─ faq.html            … ⑦よくある質問
├─ contact.html        … ⑧お問い合わせ・見学予約
├─ privacy.html        … プライバシーポリシー
├─ sitemap.html        … サイトマップ
├─ css/style.css       … 全ページ共通スタイル
├─ js/main.js          … メニュー開閉・スクロール表示アニメーション
├─ images/
│   ├─ favicon.png
│   └─ characters/     … キャラクター（加工済み）
└─ キャラクター/        … 支給いただいた元データ（未加工・保存用）
```

`index.html` をダブルクリックすればブラウザで確認できます。

## 2. デザイン方針

| 項目 | 内容 |

保護者の方が「かわいい」より先に「安心して読める」と感じられるよう、
キャラクターは主役ではなく“寄り添う存在”として配置しています。

### ロゴ

支給いただいた2種類のうち、**横組み版（`logo/yoko_color.png`）**を採用しました。
ヘッダーは高さ50〜75pxの横長スペースのため、縦組み版（`color.png`）だと1文字あたりが小さくなりすぎるためです。

| 生成ファイル | 用途 | 元データ |
|---|---|---|
| `images/logo.png` | ヘッダー（高さ40px）／フッター（高さ34px） | `logo/yoko_color.png` をトリミング＋リサイズ |
| `images/logo-mark.png` | シンボルマーク単体（今後バナー等で使う想定） | 同上の左側マーク部分を正方形に切り出し |
| `images/favicon.png` | ブラウザのタブアイコン | `logo-mark.png` を64pxに縮小 |

ロゴ本体には拡大・縮小以外の加工（色替え・要素の削除など）は行っていません。

**表示のしかた**

- ヘッダー：［ロゴ｜橋本］の横並び1行。区切り線でブランドロゴと教室名を分けています
  （読み上げソフトでは「＆kids 橋本」と読まれます）
- フッター：背景が濃い茶色（`#4A3336`）でロゴの文字色が沈むため、**白い角丸のチップに載せて**います。
  白抜き（反転）版のロゴをご用意いただければ、チップなしのすっきりした見せ方に変更できます
- 縦組み版（`color.png`）は、名刺・チラシ・SNSのプロフィール画像など正方形に近い場面に向いています。
  サイト内で使う場合は、お知らせのアイキャッチ等が候補です

### キャラクターの使い分け

| ファイル | 使用箇所 |
|---|---|
| `kid.png`（キッドくん）/ `dog-normal.png` / `ann.png`（アンちゃん） | **トップのメインビジュアル**（3匹並び） |
| `kid.png` / `ann.png` | CTA帯 |
| `husky-happy.png` | 下層ページ（アクセス）のページ見出し |
| `dog-hatena.png` | 「こんなお悩みありませんか」の吹き出し |
| `husky-b.png` | フッター（オレンジのバンダナがブランドカラーと一致） |
| `allstars.png` | ＆kids橋本について（コンセプト） |
| `avatar-*.png` | 保護者の声のアイコン（顔まわりを円形に切り出し） |

元画像はすべて余白トリミング・リサイズのみで、絵柄には手を加えていません。

メインビジュアルの3匹は、それぞれ少しずつタイミングをずらしてゆっくり上下に浮かびます。
まわりのパステルのまるとキラキラはCSSで描いており、画像ではありません（差し替え不要）。

## 4. 実装メモ

- **お問い合わせフォーム**（`contact.html`）は現在デモ動作です。送信ボタンを押すと確認メッセージが出るだけで、実際には送信されません。WordPress化の際に Contact Form 7 等へ差し替えます。
- **地図**は Google マップの埋め込み（APIキー不要）です。番地まで正確なピンにしたい場合は、Google マップで施設を検索し「共有 → 地図を埋め込む」で得られる URL に差し替えてください。
- **お知らせ**（`news.html`）は WordPress の「投稿」で運用する想定です。カテゴリーは「お知らせ／空き状況／行事／重要」の4つを想定し、トップページには最新3件を自動表示します。
- **地域SEO**：各ページの title・description・本文に「相模原市緑区橋本」「橋本駅」を自然な形で配置しています。
- **アクセシビリティ**：キーボード操作、スキップリンク、`prefers-reduced-motion`（アニメーションを減らす設定）に対応しています。
- **ブラウザ確認**：CSSを修正しても表示が変わらない場合は、キャッシュをクリア（Ctrl + F5）してください。
